L'atelier est une page web avec le code du jeu à gauche et le jeu à droite.

Aller à…Saute à une partie du code (chaque partie commence par un titre ★ ou ★★).

2. Les bases du code

Le jeu est écrit en JavaScript, le langage des pages web. Pas besoin de tout comprendre pour le modifier : voici les 8 choses que tu vas croiser partout, avec de vrais exemples tirés du jeu.

Le commentaire : du texte pour les humains

// Points de vie. Essaie 999 pour un Nexi quasi invincible.

Tout ce qui suit // sur une ligne est ignoré par l'ordinateur. Ce sont des notes pour toi. Les gros blocs entre /* et */ aussi.

La constante : un nom qui retient une valeur

const MESSAGE_KO = "SYSTEM FAILURE";

const crée une boîte nommée MESSAGE_KO qui contient le texte "SYSTEM FAILURE". Partout où le jeu écrit MESSAGE_KO, il utilise ce texte. Le ; termine l'instruction.

Les 3 types de valeurs que tu vas changer

TypeExempleRègle
Nombre100, 0.22, -5Sans guillemets. La virgule décimale s'écrit avec un point : 0.22, pas 0,22.
Texte (chaîne)"Cheval de Troie"Toujours entre guillemets " ", au début et à la fin.
Booléentrue / falseVrai ou faux, sans guillemets. Sert d'interrupteur.

L'objet : une fiche avec des cases nommées

const JOUEUR = {
  PV_MAX: 150,          // Points de vie
  VITESSE: 72,          // Vitesse de déplacement
  ONE_SHOT: false,      // true = chaque coup tue l'ennemi
};

Entre { et }, chaque ligne est un couple nom: valeur,. Le jeu lit la valeur avec un point : JOUEUR.PV_MAX vaut 150. La virgule à la fin de chaque ligne est obligatoire (sauf parfois la dernière).

Le tableau : une liste rangée

PETITS: ["ver", "glitch", "spyware", "script", "drone"],

Entre [ et ], des valeurs séparées par des virgules. Ici, la liste des petits ennemis qui peuvent apparaître. Retire "drone" et il n'y aura plus de drones.

La fonction : une recette que le jeu peut suivre

function px(x, y, c) { g.fillStyle = c; g.fillRect(x | 0, y | 0, 1, 1); }

px dessine un pixel de couleur c à la position x, y (x | 0 arrondit à un nombre entier). Le jeu appelle px(10, 20, "#ffffff") pour poser un pixel blanc. Tout le jeu est fait de fonctions comme celle-ci, qui s'appellent entre elles.

La condition : « si… alors… »

if (J.pv <= 0) mourir();

« Si les PV de Nexi (J.pv) sont inférieurs ou égaux à 0, alors appeler la fonction mourir ». Les comparaisons : === égal, !== différent, < plus petit, > plus grand.

Les couleurs : le code hexadécimal

P:"#7b3fe0"

Une couleur s'écrit # suivi de 6 caractères : 2 pour le rouge, 2 pour le vert, 2 pour le bleu, de 00 (rien) à ff (maximum). #ff0000 = rouge pur, #000000 = noir, #ffffff = blanc. Ici 7b de rouge, 3f de vert, e0 de bleu : le violet de Nexi.

3. Les missions de l'atelier

Cinq défis pour découvrir le code pas à pas. Chacun prend 2 à 5 minutes. Après chaque modification : ▶ LANCER.

Mission 1 — Nexi surpuissant (un nombre)

Change les points de vie de 100 à 999, puis la hauteur du saut de 215 à 350.

PV_MAX: 999,
FORCE_SAUT: 350,

Ce que tu dois voir : la barre de vie affiche 999, et Nexi saute très haut.
Tu as appris : un nombre dans un objet, et la virgule qui termine la ligne.

Ouvrir PV_MAX dans l'atelier Ouvrir FORCE_SAUT

Mission 2 — Renomme un boss (un texte)

troie: "Bourrin 3000",

Ce que tu dois voir : le nom en grand quand le premier mini-boss arrive (salle 7). Tu peux aussi changer le texte de la mort : MESSAGE_KO = "GAME OVER";
Tu as appris : un texte s'écrit toujours entre guillemets.

Ouvrir le nom du boss Ouvrir le texte de mort

Mission 3 — Change les règles (un booléen, un choix)

ONE_SHOT: true,
const ELEMENT = "feu";

Ce que tu dois voir : avec ONE_SHOT: true, chaque ennemi touché meurt d'un coup. Avec "feu", tes coups brûlent (les choix possibles sont écrits juste au-dessus : "aucun", "feu", "poison", "foudre", "glace", "vampire").
Tu as appris : true/false sont des interrupteurs ; un texte doit parfois être pris dans une liste précise.

Ouvrir ONE_SHOT Ouvrir ELEMENT

Mission 4 — Repeins Nexi (une couleur)

const PAL_NEXI = { K:"#14082c", P:"#e03f3f", L:"#ff7b7b", d:"#a81f1f", …

P est le violet principal du corps, L sa version claire, d sa version sombre. Change les trois avec la même teinte, plus claire et plus sombre : Nexi devient rouge (ou la couleur de ton choix).
Tu as appris : les couleurs hexadécimales, et qu'une lettre du dessin correspond à une couleur de la palette.

Ouvrir la couleur de Nexi

Mission 5 (bonus) — Crée ton propre bonus de porte (une liste d'objets)

Dans LISTE_BONUS, copie une ligne, colle-la juste en dessous et change-la :

{ nom: "Mode turbo", desc: "Vitesse +80 %", duree: 3, mods: { vitesse: 1.8 } },

Ce que tu dois voir : en passant les portes, ton bonus finit par tomber (bandeau « BONUS : Mode turbo »). Pour le tester tout de suite, mets CHANCE_BONUS: 1 dans PORTES.
Tu as appris : une liste d'objets, et qu'on code souvent en copiant puis en adaptant une ligne qui marche.

Ouvrir LISTE_BONUS

Mission 6 (bonus) — Invente ton propre élément

Dans EFFETS_ELEMENTS, copie la ligne feu, colle-la en dessous et transforme-la :

  plasma: { effet: "brulure", couleur: "#ff3300", magique: true, degatsParSec: 20, duree: 5 },

Puis, tout en haut du fichier : const ELEMENT = "plasma";

Ce que tu dois voir : le nom « plasma » en rouge sous la barre de vie, et des ennemis qui fondent. Si tu lis « ELEMENT INCONNU », les deux noms ne sont pas écrits pareil.
Tu as appris : le nom d'une ligne sert d'identifiant ailleurs dans le code ; il faut l'écrire exactement pareil aux deux endroits.

★★ CODEUR — LES DESSINSLe pantin de Nexi (poses), les palettes de couleurs, les sprites en lettres, les boss dessinés avec des formes.
★★ CODEUR — LE MOTEURLes fonctions qui font vivre le jeu : salles, ennemis, combat, équipement, sauvegarde, son, boss, mise en scène.
★★ CODEUR — AFFICHAGE ET DÉMARRAGELe dessin de chaque image, les boutons tactiles, le clavier, la boucle de jeu et le lancement.
LA RÈGLE D'OR
Plus tu descends dans le fichier, plus le code est technique. Les 150 premières lignes suffisent pour transformer le jeu.

ÉLÉMENT DES ATTAQUES

const ELEMENT = "aucun";

Remplace le mot entre guillemets par "feu" (brûlure), "poison" (se cumule à chaque coup), "foudre" (paralyse au bout de 3 coups), "glace" (ralentit) ou "vampire" (Nexi récupère de la vie en frappant). Garde les guillemets et le ;. Si le nom n'existe pas, le jeu affiche « ELEMENT INCONNU » sous la barre de vie et joue sans élément. Tu peux aussi inventer le tien : voir Les éléments.

DIFFICULTÉ DES MONSTRES

MULT_PV: 1Multiplie les PV de tous les ennemis (3 = trois fois plus résistants).
MULT_DEGATS: 1Multiplie leurs dégâts (0.5 = partie tranquille).
GAIN_PAR_SALLE: 0.045À chaque salle, les ennemis deviennent 4,5 % plus forts. Ça se cumule : en salle 30, ils sont 3,6 fois plus forts.
ENNEMIS_DEPART: 2 / ENNEMIS_MAX: 9Le nombre d'ennemis dans la 1re salle, et le maximum.
CHANCE_ELEMENTAIRE: 0.1515 % des ennemis sont élémentaires (halo de la couleur de l'élément), à partir de la salle 3.
ELEMENTS: ["feu", "foudre"]Les éléments possibles pour ces ennemis : n'importe quel nom de EFFETS_ELEMENTS ("poison", "glace", "lave", "vampire"…). Ils infligent leur effet à Nexi (voir juste en dessous).

LES ÉTATS SUBIS PAR NEXI

feu: { apresCoups: 1, apresDegats: 0, degatsParSec: 2.5, duree: 2.5 },   // Essaie apresCoups: 3

Les éléments marchent dans les deux sens : un ennemi « de glace » ralentit Nexi, un ennemi « de poison » l'empoisonne, un ennemi « de lave » pose une flaque sous ses pieds, un ennemi « vampire » se soigne en le frappant. L'effet est celui de la ligne de l'élément dans EFFETS_ELEMENTS. ETATS_NEXI règle, élément par élément, quand Nexi le subit :

apresCoupsL'état arrive au bout de X coups de cet élément (1 = à chaque coup).
apresDegatsOu au bout de X dégâts reçus de cet élément. Le premier des deux atteint déclenche l'état, puis le compteur repart de zéro.
0Coupe ce compteur. 0 aux deux : Nexi n'a jamais cet état.
les autres réglagesdegatsParSec, duree, force… remplacent ceux de EFFETS_ELEMENTS, pour Nexi seulement (pour qu'un élément soit fort contre les ennemis et plus doux contre Nexi).

Pour choisir quels éléments les ennemis peuvent avoir : ELEMENTS dans MONSTRES. Un élément inventé (comme l'acide de la recette A) marche aussi : ajoute son nom dans ELEMENTS, et il touchera Nexi à chaque coup avec ses propres réglages, sauf si tu lui ajoutes une ligne dans ETATS_NEXI.

ESSAIE
Des ennemis de glace et de poison partout : CHANCE_ELEMENTAIRE: 1 et ELEMENTS: ["glace", "poison"]. Pour que Nexi ne brûle qu'après avoir encaissé 30 dégâts de feu : feu: { apresCoups: 0, apresDegats: 30, … }.

NOMS DES BOSS ET HISTOIRE

NOMS_BOSS et TITRES_BOSS : les noms affichés en grand à l'arrivée de chaque boss. HISTOIRE.RENCONTRES_AVANT_VER_ULTIME : combien de fois on affronte le Tyran avant de trouver l'Abyssal Worm (mets 1 pour voir la fin plus vite).

PROGRESSION DE NEXI

XP_PREMIER_NIVEAU: 20XP pour passer niveau 2 (chaque niveau suivant demande XP_EN_PLUS_PAR_NIVEAU de plus).
FRAGMENTS_GARDES_A_LA_MORT: 0.25Part des fragments conservée quand Nexi meurt.
TAILLE_SAC: 6 / TAILLE_COFFRE: 12Places dans le sac et dans le coffre du Terminal.
SOIN_FRAGMENTS_PAR_PV: 0.4Prix du soin à la porte, par PV manquant.
COUT_AMELIORATION: 25 / HAUSSE_COUT: 1.6Prix d'une amélioration au Terminal : 25, puis ×1,6 à chaque fois (25, 40, 64, 102…).
CHARGE_DE_BASE: 30Le poids que Nexi porte sans être ralenti au départ.
SAUVEGARDE_AUTO: truefalse = rien n'est gardé dans le navigateur.

GAIN_PAR_POINT dit ce que rapporte 1 point dépensé au Terminal : +10 PV, +8 % de dégâts, +4 % de vitesse, +4 de défense, ou +3 de charge (endurance).

6. Les données ★★ Codeur

Ces sections décrivent le contenu du jeu sous forme de listes. Pour chacune : à quoi elle sert, comment lire une ligne, ce que tu peux changer sans risque.

TEXTES DE MORT

MESSAGE_KO et SOUS_TITRE_KO : le texte de l'écran de mort.

LES ÉLÉMENTS

glace: { effet: "ralentir", couleur: "#9fe8ff", magique: true, force: 0.5, duree: 3 },

Une ligne = un élément. Le nom avant les deux-points (glace) est celui à écrire dans const ELEMENT = "glace";. Chaque élément choisit un effet parmi les 6 que le moteur sait faire :

effetCe qu'il faitSes réglages
"brulure"Dégâts continus pendant quelques secondes.degatsParSec, duree
"cumul"Chaque coup ajoute une dose ; plus de doses = plus de dégâts.degatsParSec (par dose), duree, cumulMax
"paralysie"Remplit une jauge ; pleine, l'ennemi est figé.coupsPourParalyser, dureeParalysie, degatsBonus
"ralentir"L'ennemi bouge et attaque moins vite (deux fois moins fort sur les boss).force (0.5 = moitié moins vite, 0.9 au maximum), duree
"volDeVie"Nexi récupère une part des dégâts qu'il inflige.part (0.15 = 15 %)
"flaque"Chaque coup laisse une flaque au sol (la lave) : les ennemis dedans brûlent et ralentissent.degatsParSec, force, duree (vie de la flaque), largeur

Au bout de X coups ou X dégâts : ajoute apresCoups: 3 à une ligne et l'effet ne se déclenche qu'au 3e coup sur le même ennemi ; ou apresDegats: 40 et il se déclenche quand l'ennemi a encaissé 40 dégâts. Une petite jauge de la couleur de l'élément se remplit au-dessus de l'ennemi, puis repart de zéro. Exemple, un feu qui n'enflamme qu'au 3e coup mais brûle fort :

feu: { effet: "brulure", couleur: "#ff8a3c", magique: true, degatsParSec: 15, duree: 3, apresCoups: 3 },

(La foudre a déjà son propre compteur : coupsPourParalyser.) Pour l'autre sens, quand un ennemi élémentaire touche Nexi, c'est ETATS_NEXI (section 5).

Deux options de plus : magique: true permet de blesser les Spectres sans compétence, spectresImmunises: true rend les Spectres insensibles à l'élément. couleur colore le nom de l'élément, les particules et l'onde.

À TOI
Pour créer ton élément : copie une ligne, change le nom, l'effet, les chiffres et la couleur, puis écris ce nom dans ELEMENT (mission 6). Ajouter un 7e type d'effet demande d'écrire du code dans la fonction appliquerElementType : c'est un vrai défi de codeur. La recette A (section 9) montre comment la flaque de lave a été ajoutée.

LES PORTES (bonus et malus)

{ nom: "Surcharge offensive", desc: "Dégâts +20 %", duree: 3, mods: { degats: 1.2 } },

À chaque porte, le jeu tire un bonus (liste LISTE_BONUS) ou un malus (LISTE_MALUS). duree = nombre de salles. mods multiplie une caractéristique (vitesse, degats, cadence, cooldownLourd, pvEnnemis). ajouts ajoute une valeur (pvParPulsation). drapeaux active un effet spécial déjà codé (gardien, foudreAuto, parasite…). PORTES.CHANCE_BONUS règle la chance d'avoir un bonus. Dans la salle de repos, bonus et malus sont en pause.

LOOT (le butin)

Les chances (entre 0 et 1) : fiole de soin, coffre dans une salle, objet lâché par un ennemi, arme enchantée de feu ou de foudre. NIVEAU_TOUTES_LES: 12 : les objets trouvés gagnent 1 niveau toutes les 12 salles.

BESTIAIRE

ver: { nom: "Ver informatique", pv: 18, degats: 10, vitesse: 30, apparitionDes: 1, poids: 3 },

Une ligne par ennemi. apparitionDes = première salle où il peut apparaître, poids = sa fréquence (plus grand = plus courant). spectre: true le rend résistant aux coups physiques, defense: 0.5 lui fait perdre moitié moins de PV. Le comportement de chaque ennemi est codé dans la fonction majEnnemi. element: "glace" rend cet ennemi toujours élémentaire. Pour inventer un ennemi : comme (copier un ennemi existant), teinte (changer ses couleurs), dessin et palette (son propre dessin). Voir la recette B, section 9.

PROGRESSION DES SALLES

PROGRESSION.CYCLE décrit un cycle de 6 salles : on ajoute des petits ennemis, puis des gros, puis le mini-boss (elite: true). Juste avant chaque mini-boss, le jeu insère une salle de repos (Terminal). Chaque nouveau cycle recommence avec un ennemi de plus.

LES BOSS et LES VIRUS

BOSS donne les PV et les dégâts de base de chaque boss. GAIN_PAR_CYCLE: 0.55 : à chaque cycle, leurs PV sont multipliés par 1,55 (et leurs dégâts par 1,25). ARCHONTE_TOUS_LES: 2 : le Tyran revient tous les 2 cycles. Chaque mini-boss vaincu lâche un virus (liste VIRUS) : une compétence qui remplace l'onde, avec son avantage (effet), son défaut (contre) et son temps de recharge. Pour inventer un mini-boss à partir d'un boss existant : comme, teinte et titre, puis son nom dans ORDRE (recette C, section 9).

LES ARMES

katana: { nom: "Katana Fibre", cat: "epee", poids: 3, degats: 10, gain: 1.5, portee: 1.4, desc: "Lame fine, portée plus longue" },
catLa catégorie, qui décide de la façon de frapper : "epee" (combo de 3 coups), "fouet" (2 coups longs), "lourde" (1 grand coup lent), "distance" (tirs, avec forme "arc" ou "baton").
degats / gainDégâts au niveau 1, puis dégâts en plus à chaque niveau.
poidsCompte dans la charge de Nexi.
vitesse / porteeMultiplicateurs (1 = normal).
element / effetFeu ou foudre intégrés ; effet spécial déjà codé ("parefeu", "chaine", "onde", "minage"…).
corrompue: trueFait partie du set corrompu lâché par le Tyran.

LES ARMURES et LE POIDS

Chaque armure a une piece (casque, plastron, gantelets, bottes), une defense et un poids. Les dégâts reçus sont multipliés par 50 / (50 + défense) : avec 50 de défense, Nexi prend moitié moins. La section CHARGE règle les seuils : jusqu'à 30 % de la charge max, Nexi est léger (+10 % de vitesse) ; au-delà de 70 %, il est lourd (−20 % de vitesse et d'attaque). Le set corrompu complet (4 armures + 1 arme corrompue) active une synergie selon le virus équipé (liste SYNERGIES).

LA MUSIQUE et LES BRUITAGES

exploration: { tempo: 116, ondeMelodie: "square",
  melodie: "E4 - - G4 - - B4 - A4 - G4 - F#4 - - - …",

Aucun fichier son : le navigateur fabrique les notes. Une note = une croche : E4 = mi de l'octave 4, F#4 = fa dièse, - tient la note, . = silence. Batterie : k grosse caisse, s caisse claire, h charleston. tempo = vitesse en battements par minute. Dans BRUITAGES, de et a sont les fréquences de départ et d'arrivée d'un son (en hertz).

LES PIÈGES et LE MONDE

PIEGES règle la chance d'avoir des pièges dans une salle et la force de chaque type : la mine (explosif), la grille de flammes (brulant) et l'arc électrique (foudroyant), avec leurs temps actif et repos. MONDE.GRAVITE: 540 : la force qui ramène Nexi au sol (essaie 200 pour la Lune). LARGEUR_SALLE: 560 : la longueur des salles en pixels.

7. Dessins, couleurs et animations

Le pantin de Nexi : les poses

leger2: { brasB: 160, brasF: 5, jambeB: 125, jambeF: 50, epee: 0, dx: 1, yeux: "plisses" },

Nexi est un pantin : chaque pose donne l'angle (en degrés) de ses bras, jambes et de son arme. 0 = vers la droite, 90 = vers le bas, -90 = vers le haut. dx/dy décalent le corps, yeux: "plisses" plisse les yeux. Change un angle de la pose repos1 et Nexi se tient autrement. Le dessin à partir de ces angles est fait par la fonction rendrePose.

Les palettes et les sprites en lettres

const PAL_ZOMBIE = { L:"#e4dcff", l:"#a796e0", d:"#6a58a8", D:"#0c0716", E:"#FF5E7A", … };
const ZOMBIE = [".........LLLL.........", ".......LLllllLL.......", …

Les petits ennemis sont dessinés en texte : chaque chaîne est une ligne de pixels, chaque lettre une couleur de la palette, le point . un pixel transparent. Change E:"#FF5E7A" (les yeux du zombie) en "#3DF5C4" et ses yeux deviennent verts. Un contour sombre est ajouté automatiquement.

Les boss : des formes géométriques

Les boss sont trop grands pour être dessinés lettre par lettre : ils sont construits avec des formes (rect, ellipse, capsule, poly) et des matériaux à 3 tons. La fonction rendreFormes transforme ces formes en pixels, avec ombres et contour automatiques. Les tailles de chaque boss sont dans TAILLES_BOSS.

8. Le moteur du jeu

Pour ceux qui veulent comprendre comment le jeu fonctionne vraiment.

La boucle de jeu : 60 fois par seconde

boucle() ── appelée environ 60 fois par seconde par le navigateur └─ image() ├─ lireTouches() quelles touches / quels boutons sont appuyés ? ├─ maj(dt) faire avancer le monde de dt secondes (≈ 0,016) │ ├─ majJoueur déplacements, sauts, attaques de Nexi │ ├─ majEnnemi chaque ennemi bouge et attaque (majBoss pour les boss) │ ├─ tirs, pièges, butin, Terminal, porte… └─ dessiner() redessiner toute l'image : décor, ennemis, Nexi, HUD

dt (« delta temps ») est le temps écoulé depuis l'image précédente. Tout ce qui bouge est multiplié par dt : e.x += e.dir * 130 * dt veut dire « avancer de 130 pixels par seconde », quelle que soit la vitesse de l'ordinateur.

Les états du jeu

La variable etat dit où on en est : "titre", "histoire", "jeu", "menu" (pause, Terminal, inventaire…), "ko", "victoire". Le monde n'avance que quand etat === "jeu" : c'est ce qui met le jeu en pause dans les menus.

Les salles

infoSalle(n) calcule ce qu'est la salle numéro n (normale, Terminal, mini-boss, Tyran, sanctuaire) en rejouant les cycles depuis le début. chargerSalle(n) vide la salle précédente et crée la nouvelle : ennemis (compositionSalle), coffre, pièges, boss. salleSuivante() est appelée quand Nexi passe la porte : elle tire un bonus ou un malus puis charge la salle.

Les boss : des attaques au choix

troie: ["ruee", "martelage", "ventre"],

KITS donne la liste des attaques de chaque boss ; le boss en pioche une, l'exécute, fait une pause, puis recommence. Chaque attaque est une fonction de ATTAQUES, appelée à chaque image tant qu'elle n'est pas finie (elle renvoie true quand elle a terminé). Par exemple, la ruée du Cheval de Troie : il gratte le sol 0,9 seconde (un « ! » apparaît), puis fonce à 130 pixels par seconde jusqu'au mur.

Équipement, Terminal et menus

Un objet est une petite fiche { id, type, niv } (et parfois element). equiper le place sur Nexi et range l'ancien dans le sac. Tous les menus (pause, Terminal, inventaire, réglages) passent par ouvrirMenu, qui reçoit un titre et une liste de lignes : chaque ligne a un texte et une action (la fonction lancée quand on la choisit).

La sauvegarde

Au Terminal, instantane() prend une « photo » de la partie, encoderSauvegarde() la transforme en code NEXI-XXXX-…, rangé dans le navigateur (localStorage). En pleine descente, la partie n'est pas sauvegardée : quitter compte comme une mort. Le même code peut s'afficher en QR code, se copier ou se télécharger.

Le son et l'affichage

La musique est jouée par planifierMusique, qui prépare les notes un peu en avance pour un rythme parfait ; son("coup") joue un bruitage. Côté image, tout est dessiné en basse résolution (environ 280 × 130 pixels) puis agrandi sans flou : c'est ce qui donne le style pixel art. rect, px et texte sont les trois fonctions de dessin de base.

Recettes pas à pas

Le tableau dit où aller. Ces recettes montrent le code complet, prêt à copier : on part toujours d'une ligne qui marche, on la copie, puis on la change.

Recette A — De la lave qui reste au sol

Ce que tu vas obtenir : chaque coup de Nexi laisse une flaque de lave par terre. Les ennemis qui marchent dedans brûlent et sont ralentis. Les ennemis volants passent au-dessus.

La lave existe déjà dans EFFETS_ELEMENTS :

lave: { effet: "flaque", couleur: "#ff5a1f", magique: true, degatsParSec: 8, force: 0.4, duree: 4, largeur: 30 },

Pour l'activer, tout en haut du fichier : const ELEMENT = "lave";

RéglageCe qu'il change
degatsParSecLes dégâts par seconde pour un ennemi debout dans la flaque.
forceLe ralentissement : 0.4 = 40 % moins vite, 0.9 au maximum, 0 = pas de ralentissement.
dureeLe nombre de secondes avant que la flaque refroidisse.
largeurLa taille de la flaque, en pixels (Nexi en fait environ 16).

Va plus loin : invente ta propre flaque en copiant la ligne. Une flaque d'acide verte, large et lente :

acide: { effet: "flaque", couleur: "#b6ff3a", degatsParSec: 4, force: 0.7, duree: 6, largeur: 50 },

Une arme de lave : dans ARMES, copie la ligne overheat et donne-lui l'élément "lave". Elle apparaîtra dans les coffres, même si ELEMENT vaut "aucun" :

magmaBlade: { nom: "Lame de magma", cat: "epee", poids: 4, degats: 9, gain: 1.3, element: "lave", desc: "Laisse de la lave au sol" },

Comment c'est codé (pour les codeurs) : trois petites fonctions. poserFlaque ajoute une flaque dans la liste flaques quand un coup touche (ou ravive celle qui est déjà là). majFlaques est appelée 60 fois par seconde : elle vieillit chaque flaque et, pour chaque ennemi qui a les pieds dedans, réutilise la brûlure et le ralentissement qui existaient déjà. dessinerFlaques la dessine avec des bulles. C'est la bonne façon d'ajouter un effet : réutiliser ce que le moteur sait déjà faire.

Recette B — Un nouveau monstre

Trois niveaux : fais le premier, puis continue si tu as le temps.

Niveau 1 : un cousin d'un monstre existant (2 minutes). Dans BESTIAIRE, copie la ligne ver, colle-la en dessous et ajoute comme et teinte :

verLave: { nom: "Ver de lave", pv: 25, degats: 12, vitesse: 40, apparitionDes: 1, poids: 3, comme: "ver", teinte: 40 },

comme: "ver" : il bouge, se dessine et a la taille du ver. teinte: 40 décale ses couleurs (un nombre de 0 à 360, comme un tour de la roue des couleurs : 180 = couleurs opposées). Ensuite, dans PROGRESSION, ajoute son nom dans la liste des petits ennemis, sinon il n'apparaîtra jamais :

PETITS: ["verLave", "ver", "glitch", "spyware", "script", "drone"],

Ce que tu dois voir : des vers orange dès la salle 1. Pour un gros ennemi, mets comme: "trojan" et ajoute son nom dans GROS.

Niveau 2 : son propre dessin. Ajoute une palette (une lettre = une couleur) et un dessin (une chaîne = une ligne de pixels, . = transparent). dessin2 est la 2e image, pour qu'il s'anime. Sa taille se calcule toute seule d'après le dessin :

cookie: { nom: "Cookie traqueur", pv: 20, degats: 8, vitesse: 35, apparitionDes: 1, poids: 3, comme: "ver",
  palette: { K: "#1a0d05", c: "#d99a4e", p: "#3b1d0a", E: "#FF5E7A" },
  dessin:  ["...KKKKK...", "..KcccccK..", ".KccpccpcK.", "KcccEccEccK",
            "KcpccccccpK", "KcccccpcccK", ".KccpccccK.", "..KKKKKKK.."],
  dessin2: ["...KKKKK...", "..KcccccK..", ".KcpccpccK.", "KcccEccEccK",
            "KccccpcccK.", "KcpcccccpcK", ".KcccccpcK.", "..KKKKKKK.."] },

N'oublie pas "cookie" dans PETITS. Astuce : dessine d'abord sur du papier quadrillé, une case = une lettre.

Niveau 3 : son propre comportement (codeur). Enlève comme: "ver" de la ligne du cookie. Puis, dans la fonction majEnnemi, ajoute un case à côté de celui du ver. Le cookie saute vers Nexi toutes les 1,5 seconde :

    case "cookie": { // saute vers Nexi
      e.dir = Math.sign(dx) || e.dir;               // se tourne vers Nexi
      e.chrono -= dt;                               // compte à rebours avant le prochain saut
      if (e.chrono <= 0 && e.y >= e.baseY) { e.vy = -170; e.chrono = 1.5; }
      e.vy += MONDE.GRAVITE * dt;                   // la gravité le ramène au sol
      e.y = Math.min(e.baseY, e.y + e.vy * dt);
      if (e.y < e.baseY) e.x += e.dir * e.vitesse * 2 * dt;   // avance seulement en l'air
      break;
    }

dx est la distance jusqu'à Nexi (négative s'il est à gauche), dt le temps écoulé depuis la dernière image, e.baseY la hauteur du sol pour ce monstre. Change -170 (la force du saut) ou 1.5 (le temps entre deux sauts) pour voir.

Recette C — Un nouveau mini-boss

Un boss a beaucoup de pièces (dessin en formes, attaques, virus lâché à sa mort). Le plus simple : en prendre un existant comme modèle, puis changer son nom, ses couleurs et sa force. Dans BOSS, ajoute une ligne sous celle du Tyran :

givre: { nom: "Cheval de givre", titre: "Le présent gelé", pv: 300, degats: 18, comme: "troie", teinte: 200 },

Puis mets son nom au début de ORDRE, pour l'affronter en premier :

ORDRE: ["givre", "troie", "botnet", "zombie", "e404", "kernel"],

Ce que tu dois voir : en salle 7, « CHEVAL DE GIVRE » et son titre s'affichent en grand. Il a les attaques et le dessin du Cheval de Troie, en bleu glacé. Vaincu, il lâche le virus de son modèle. Pour le tester vite, baisse pv à 50.

Va plus loin (codeur) : la liste KITS donne les attaques de chaque boss. Retire "ventre" de la ligne troie et ton Cheval de givre n'ouvrira plus jamais son point faible (le vrai Cheval de Troie non plus, car il partage la même liste). Chaque attaque est une fonction de ATTAQUES : lis martelage, la plus courte, pour comprendre comment elles marchent.

Pas de panique : une faute de frappe arrête le jeu, mais l'atelier te dit où elle est. Le message rouge indique une ligne : la faute est sur cette ligne ou juste au-dessus.

La virgule décimale française : 0,5 casse la ligne, écris 0.5. Et ne supprime pas les lignes qui commencent par function : ce sont les recettes du jeu.
